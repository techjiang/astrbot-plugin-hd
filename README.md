## 🚀 安装

把本仓库内容放进 AstrBot 的 `data/plugins/astrbot_plugin_hudong/` 目录，
重启 AstrBot 或在 WebUI 插件页重载即可。

```
data/plugins/astrbot_plugin_hudong/
├── main.py              # 主入口：指令注册与编排
├── games.py             # 玩法算法（纯逻辑，无副作用）
├── store.py             # 会话隔离持久化
├── _conf_schema.json    # WebUI 可视化配置
├── metadata.yaml        # 插件元数据
├── requirements.txt     # 无第三方依赖
├── __init__.py
└── tests/               # 单元测试
```

无需安装任何第三方库，仅使用 Python 标准库。

## ⚙️ 配置

在 AstrBot WebUI 的插件配置页可视化调整，无需改代码：

- **基础**：插件总开关、积分名称
- **签到**：奖励区间、连续签到加成系数与上限
- **抽奖**：消耗积分、冷却时间
- **猜数字**：数字范围、最大次数、猜中奖励
- **词语接龙**：超时时间、每次奖励
- **投票**：最大选项数、持续时长
- **排行榜**：显示人数
- **打劫 / 掷骰**：独立开关
- **关键词互动**：自定义「关键词 → 回复」规则
- **权限**：是否仅群聊生效、指令冷却

## 💾 数据存储

数据保存在 `data/astrbot_plugin_hudong/<平台>_<群或私聊>.json`，
按平台与会话隔离，插件升级不丢数据。写入采用「临时文件 + 原子替换」，
并做节流与线程池序列化，不会阻塞事件循环。
