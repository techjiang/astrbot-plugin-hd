# 互动 · AstrBot 群聊互动插件

> 让群聊热闹起来的一站式互动玩法合集。

「互动」是一个为 AstrBot 打造的新一代群聊互动插件，内置签到、积分、抽奖、
投票、猜数字、词语接龙、排行榜与关键词互动等玩法。所有数据按会话隔离并
持久化保存，开箱即用。

## ✨ 功能一览

| 玩法 | 指令 | 说明 |
| --- | --- | --- |
| 每日签到 | `/签到`（别名 `sign`、`打卡`） | 领取随机积分，连续签到有额外加成 |
| 积分查询 | `/积分`（别名 `余额`、`balance`） | 查看余额与个人统计 |
| 积分转账 | `/转账 <@用户> <数量>` | 把积分转给群友 |
| 抽奖 | `/抽奖`（别名 `抽卡`、`lottery`） | 消耗积分抽奖，含称号/头像框等稀有奖品 |
| 猜数字 | `/猜数字` → `/猜 <数字>` | 区间内猜数字，有大小提示与接近提示 |
| 词语接龙 | `/接龙 [起始词]` | 自动识别群里的接龙词语，交替接龙 |
| 投票 | `/投票 问题 \| 选项1 \| 选项2`<br>`/投 <编号> <序号>`<br>`/投票结果 <编号>` | 发起/参与/查看投票，带文字进度条 |
| 排行榜 | `/排行榜 [积分\|签到\|抽奖\|猜中\|接龙]` | 本群多维度排行榜，前三名有奖牌 |
| 关键词互动 | 配置触发 | 消息命中关键词自动回复 |

## 🚀 安装

将本插件目录放入 AstrBot 的 `data/plugins/` 下，重启或在 WebUI 插件页重载即可。

```
data/plugins/astrbot_plugin_hudong/
├── metadata.yaml
├── _conf_schema.json
├── main.py
├── games.py
├── store.py
├── requirements.txt
└── README.md
```

无需额外第三方依赖。

## ⚙️ 配置

在 AstrBot WebUI 的插件配置页可视化配置，可自定义：

- **积分名称**：默认「互动币」
- **签到**：奖励区间、连续签到加成系数与上限
- **抽奖**：消耗积分、冷却时间
- **投票**：最大选项数、持续时长
- **猜数字**：数字范围、最大次数、猜中奖励
- **接龙**：超时时间、奖励
- **排行榜**：显示人数
- **关键词互动**：自定义关键词 → 回复规则
- **权限**：是否仅群聊生效、指令冷却

## 📦 数据存储

数据保存在 AstrBot 数据目录下的 `data/interaction/<平台>_<会话>.json`，
按平台与群/私聊隔离，随插件更新不会丢失。
